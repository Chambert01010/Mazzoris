Mazzoris Web App Walkthrough
I have successfully created the Mazzoris Django web application with the following features:

Features Implemented
Home Page: Integrated the original landing page with a "Login" button.
User Authentication: Login system with a custom template.
Dashboard: A user-friendly dashboard with buttons for BBVA, Banorte, Scotiabank, and Inbursa.
Bank Statement Processing:
BBVA: Extracts data using coordinate-based logic.
Banorte: Extracts data using text-based logic.
Scotiabank: Extracts data using regex and date logic.
Inbursa: Extracts data using regex and keyword logic.
Excel Export: All processed statements are returned as downloadable Excel files.
